# rqgame

Code for *Action-Mapping Design for Self-Enforcing Cooperation in Entanglement-Mediated Supply-Chain
Resilience as a Mechanism-Design Result with Quantum Game Theory* (R. Palanivel).

Exact statevector simulation only (NumPy/SciPy, CPU). No quantum-advantage claim.

## Layout
| path | content |
|---|---|
| `src/rqgame/game.py` | classical game, Y-entangler EWL circuit, faithful-embedding check, regret (grid + Nelder-Mead, full SU(2)), best-response search, learners' reduced game |
| `src/rqgame/qaoa.py` | QUBO to Ising, exact-statevector QAOA, Ramanujan and control biases |
| `src/rqgame/marl.py` | reward kernels (EWL, classical fine), Rogers-Ramanujan / hyperbolic schedules, independent Q-learning, frozen-policy evaluation |
| `src/rqgame/ops.py` | operational model, coupling rules, Algorithm 1 (`pipeline`), benchmark methods |
| `src/rqgame/shapley.py`, `stats.py` | Shapley values, interaction indices, bootstrap; Holm, rank-biserial, Wilcoxon |
| `scripts/` | one script per research question; `run_all.sh` runs everything |
| `tests/test_all.py` | 27 tests (the 26 listed in Appendix C plus one low-regime fine caveat) |
| `paper/make_springer.py` | converts the article-class `.tex` into Springer Nature `sn-jnl` format |

## Quick start
```bash
pip install -e ".[dev]"
pytest -q
python scripts/rq_reduced_game.py          # seconds
python scripts/rq1_equilibria.py           # ~1-2 min
python scripts/rq3_benchmark.py 3 exact    # fast smoke run; use `30 qaoa` for the full run
./run_all.sh                               # full pipeline (long)
```

## Conventions (and choices the manuscript leaves open)
* Bit order is big-endian; `0` = Invest, `1` = Not-invest; roles are S, M, L, R.
* Low/High regime disruption probabilities are `0.5 s` / `1.5 s`; at s = 0.3 the Low regime is p_d = 0.15.
* Greedy tie-breaking in Q-learning defaults to **Invest** (`tie="invest"`). This matters for the aware
  mapping, which induces a coordination game; `tie="not"` gives much lower investment.
* "Classical MARL (role gating)" is implemented as the pipeline with the classical kernel, standard mapping,
  and no Ramanujan bias. The manuscript does not pin this down further.
* QAOA allocations are the modal bitstring of the optimised state.

## Reproduction status
Verified by the test suite: classical payoffs and dominance, faithful embedding (Y) and its failure (X),
regret of (iZ)^4 on S and full SU(2), Ising/binary equality, QAOA invariants, R_YY decomposition,
learners' reduced-game equilibria (matches paper Table 3 at p_d = 0.15), Shapley ground truth.
The operational-benchmark and MARL tables are regenerated by the scripts; check them against the manuscript
before citing, since individual draws, tie-breaking and search seeds are implementation details.
